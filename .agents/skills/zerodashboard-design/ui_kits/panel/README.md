# UI kit — Panel (P2)
Mockup navegable: `index.html` (`data-surface="panel"`). Flujo: Mis automatizaciones (CH-22, con aviso de falla P3h) → Ajustar (CH-23) / Ver último resultado (CH-27, tabla o gráfico) / Activar disponible → advertencia de frescura (CH-26). "Salir" lleva al Ingreso (CH-22). Sin SQL ni términos técnicos. Responsive: probar a 375 px.

> **Fuera de alcance (DEC-93):** la pantalla "Último resultado" (CH-27) y el botón "Ver último resultado" de este mockup no se construyen. El sistema no persiste el contenido de las filas; el cliente recibe el resultado por correo.
