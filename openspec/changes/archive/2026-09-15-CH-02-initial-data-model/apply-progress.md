## Deviations from design.md (both documented as amendments in design.md itself)

1. Seed script imports the generated Prisma client from `dist/generated/prisma/client.js`, not `src/generated/prisma/client.js` — the runtime image never contains `src/`.
2. The migration file was generated by running `prisma migrate dev` directly on the host against a temporarily port-exposed `db` container, not inside a throwaway Docker container — two container-based approaches lost the generated file or silently failed to bind-mount to the host.
